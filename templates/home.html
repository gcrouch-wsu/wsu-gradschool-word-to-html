Upload your manual

You can upload your Word file and, in the same step, add an optional heading map file from a previous run so WordPress section links can stay pointed at the right place. Nothing here requires code—just file pickers and checkboxes.

1. Start from Word (recommended)

Choose your manual as a .docx file. If you used this tool before, use the second file picker in the shaded box to attach your heading map together with the Word file, then click the button at the bottom.

Conversion options

Which options should I pick?

  • Already uses decimal Chapter/Section numbers in Word (e.g. Chapter 4.2) and you want those kept → choose Keep the Word file’s heading numbers below. You can leave “Show numbers in the heading text” unticked; this mode keeps numbers either way.
  • Being renumbered (old letter/Roman scheme → new decimals) → choose Map body cites to new heading numbers (default).
  • Chapter vs Section labels → usually leave on Auto. Override only if Auto gets it wrong (headings should say Chapter… or Section…).

Controls the word on numbered headings and cross-references. Auto looks for Chapter/Section in the document — not cover-page keywords.

“Map…” runs a heading-number review, then links old cites to new numbers. “Keep…” skips that review and matches cites to the numbers already in the Word file.

Only applies when mapping to new numbers. With “Keep the Word file’s heading numbers,” originals are always kept — this checkbox is ignored in that mode.

Note: “Show numbers in the heading text” with “Map body cites to new heading numbers” keeps the old numbers in the HTML while references are remapped to new numbers. That is unusual — leave this unticked unless you know you need it.

Advanced (usually leave off)

Uses the document’s list/numbering definitions when Heading styles are missing or wrong. Leave off unless a conversion mis-levels headings.

Removes more local character/paragraph formatting so the site stylesheet has a cleaner slate. Can change how bold/italic look.
